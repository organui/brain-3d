# OrganUI Brain

An open-source interactive 3D brain explorer from [OrganUI](https://github.com/organui).

**Status:** repository initialized; implementation has not started. The focused build task will select and inspect licensed anatomy assets, implement the explorer, and verify it locally. There is no hosted demo yet.

## Direction

Build a small, polished application for exploring the brain through rotation, selection, a searchable anatomy panel, and views that reveal supported structures. Match the clean, warm-neutral presentation of [Heart](https://github.com/organui/heart-3d), [Liver](https://github.com/organui/liver-3d), and [Lungs](https://github.com/organui/lungs-3d).

The exact anatomical scope depends on inspected source geometry. Planned features are not implemented features, and catalog entries alone do not establish selectable meshes.

See [the build brief](docs/BUILD_BRIEF.md) for scope, source candidates, and acceptance criteria. Verified installation instructions and screenshots will be added with the application.

## Repository

This is a standalone repository with its own application, dependencies, assets, documentation, and Git history. It does not require the OrganUI monorepo or sibling organ checkouts to run.
